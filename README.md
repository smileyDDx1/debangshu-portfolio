# Backend Developer Portfolio

A clean, professional, single-page portfolio website designed specifically for backend software developers.

## Features
- **Vanilla HTML/CSS/JS**: No frameworks, lightweight, and fast.
- **Fully Responsive**: Mobile-first design.
- **Customizable**: Easy to change colors, fonts, and content.
- **Smooth Animations**: Scroll reveal and hover effects.

## Customization

1. **Information**: Open `index.html` and search for `[Your Name]`, `[X]`, `[Company Name]`, etc., and replace them with your actual details.
2. **Colors**: Open `style.css` and modify the variables in the `:root` pseudo-class at the very top. For example, change `--primary-color` to your preferred accent color.
3. **Links**: Ensure you update the `href` attributes for all social links, GitHub icons, and live demo buttons.
4. **Form**: The contact form currently simulates submission. Connect it to a service like [Formspree](https://formspree.io/) or [Netlify Forms](https://docs.netlify.com/forms/setup/) by changing the `action` attribute in the `<form>` tag.

## Deployment

Since this is a static website, you can easily deploy it for free using:
- **GitHub Pages**
- **Vercel**
- **Netlify**
- **Cloudflare Pages**

Simply push this folder to a GitHub repository and connect it to any of the services above.
